Minerva status pill for short labels — counts, states, categories.

```jsx
<Badge tone="red">Overdue</Badge>
<Badge tone="teal" soft dot>Done</Badge>
```

Tones map to the status palette: `orange` (soon), `red` (urgent), `teal` (done), `blue` (info), `navy`, `grey`. `soft` swaps the solid fill for a pastel tint with dark ink; `dot` adds a leading status dot.
