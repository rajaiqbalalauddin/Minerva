Minerva task block — a colored card with a pixel title and a due-time line. Color encodes urgency: `red` overdue/today, `orange` upcoming, `teal` later/done.

```jsx
<TaskChip title="Assignment" time="7.00 a.m , Today" tone="red" />
<TaskChip title="Watch Anime" time="9.00 a.m , 27 June" tone="teal" done />
```
